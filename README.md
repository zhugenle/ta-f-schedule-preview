# TA-F 排期看板 · 当前案例快照

[打开预览网站](https://ta-f.genle.cc/) · [GitHub Pages 备用地址](https://zhugenle.github.io/ta-f-schedule-preview/)

该公开预览版以本地看板在 2026 年 11 月 13 日的项目和排期为初始数据，包括 SDJ、ITC、SUAVE、APA 的 24 个项目、76 个排期节点、项目图片、表单样式以及三个来源截图。访问者可新建和编辑项目、节点与记录，查看甘特图和月度统计，导入记录、复制排期表单并下载 Excel。

每位访问者的编辑只保存在自己的浏览器，不会同步给其他人，也不会写回本地数据库。更换浏览器或清除网站数据会丢失这些编辑；请使用“导出本机数据”保存 JSON 备份。以后本地看板的变更需要重新构建并发布快照，才会更新线上初始数据。

本仓库不包含局域网数据库、团队账号或原始 Excel 文件。
