# TA-F 排期看板 · 功能预览

[打开预览网站](https://zhugenle.github.io/ta-f-schedule-preview/)

这是可编辑的 GitHub Pages 预览版。可以新建品牌和项目、调整 R1–RX 与 PSD 节点、记录状态、查看甘特图与月度统计、导入记录、复制表单以及下载 Excel。

初始数据均为虚构示例。每位访客的编辑仅保存在自己的浏览器中，刷新后仍在，但不会同步给其他人。更换浏览器、清除网站数据或使用无痕窗口会失去这些编辑；请使用页面上的“导出本机数据”保存 JSON 备份。可以通过“导入记录”再次导入。

正式局域网版使用单独的服务器和数据库。本仓库不包含真实客户排期、账号、数据库或来源截图。
